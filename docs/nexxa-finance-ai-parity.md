# Finance AI: Nexxa parity map (fai = finance AI agent)

Backend: `Lib/business/financeAi.ts` (+ `cashflowForecastCore.ts`, `anomalyCore.ts`, tests in `Lib/business/__tests__/`), `Controllers/financeAiController.ts`, routes under `/<panel>/biz/finance/ai/*` (`Routers/businessRoutes.ts`, gated by the panel's readFinance / manageAccounting and the licence "accounting" module), payslip under `/<panel>/payroll/ai/payslip` (payroll ACL), `aiCompleteWithImage` in `Lib/aiSettings.ts`.
Frontend: `Components/_Common/Business/Finance/Ai/*`, page `/<panel>/finance/ai` (tabs), menu item `finNavAi`.
Provider: always the CLINICAL provider of `getAiSettings()` (in-country Ollama unless the super admin chose the cloud). Nothing is posted by the AI; every result is a draft posted by the browser through the suite's normal endpoints after the user confirms. Limit: the panel AI's shared per-user daily limit (`AppConfig.panelAiDailyLimit`, `consumeAi(user, "finance.<feature>")`); detail log in `BizAiUsage` (user/day/panel/feature, failures, chars).

## Profile awareness
- No account code is hard-coded: accounts are found by role, then by name (`findAccounts`), money accounts by the owner's own till/bank list; OCR/NL/categorisation choose from the ledger's own detail accounts (list sent to the model, answer validated against it).
- `profileView(owner)`: pharmacy / hospital / clinic / paraClinic / doctor / insurance each give example questions, insurer delays, facts, checks and forecast flows.

## For the accounting agent
- Your new voucher editor already has the AI bar (`Acc/AccJournal.tsx`, 10 lines, new voucher only).
- To add the analysis block on any of your tabs: `import { AiInsight } from "../Finance/Ai/finAi";` then `<AiInsight kind="bankrec|costcenter|tax|depreciation|budget|treasury|finance" api={`${api}/finance`} />` (api = `/<panel>/biz`). It renders nothing when the AI is off or on the platform books.
- The entry draft posts manual vouchers to `POST /<panel>/biz/vouchers` (your createVoucher) with `{date, description, lines:[{account, debit, credit, label}]}`.
